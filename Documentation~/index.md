# KTX for Unity WebGL Sub-Package Documentation

This package contains a Unity version specific WebGL native library (in the form of pre-compiled, binary [WebAssembly][wasm]).

By itself it provides no functionality. It is a sub-package of its main package [KTX for Unity][KtxForUnity].
